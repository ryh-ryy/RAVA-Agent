# Data access and replication manifest

This repository does not redistribute CMB-Exam questions, answer labels, or full benchmark files. Download the dataset from its official source and follow the original licence/terms.

`replication_manifest.csv` identifies the 500-item source_id-disjoint replication sample used in the reported three-model experiment. It intentionally contains only identifiers and strata—not question text, options, or gold labels. Join the manifest locally to an authorised copy of the benchmark before running experiments.

The initial exploratory 500-item sample and pilot/smoke sets are not required to reproduce the headline three-model replication result and are not included here.
