# Aggregated results

The JSON files in this folder are aggregate paired-comparison outputs. They contain no prompts, benchmark question text, gold labels, model completions, credentials, or patient information.

`qwen_*`, `kimi26_*`, and `deepseek0731_*` correspond to the source_id-disjoint 500-item replication. The comparisons are exploratory, two-sided exact McNemar tests without multiplicity adjustment. Remote timing is not interpreted as a causal compute-speed comparison because it includes network, provider queueing, and service-side variation.
